# Aplicación Móvil en Expo / React Native - SISTEMA_SALES S.A.

Esta aplicación corresponde al **Capítulo 9.6 (Desarrollo Móvil)** y a las **Figuras 8 y 10** de la tesis de grado del Instituto Superior Tecnológico Japón.

### Estructura de Directorios (Figura 10):
```
app/
├── login/
├── dashboard/
├── productos/
├── clientes/
├── ventas/
├── facturas/
└── compras/
```

### Ejecución:
```bash
npm install
npx expo start
```
Se puede ejecutar en Expo Go para Android, iOS o en modo Web (`npx expo start --web`).
